# Imagem explicativa de caracteristicas básica das Letras de Crédito Imobiliário

## 📒 Descrição
Criação de imagem com informações explicativas sobre os investimentos e Letras de Crédito Imobiliário.
O material possibilita a pessoas sem conhecimento sobre essa alternativa de investimento a conhecer o funcionamento básico do produto.

## 🤖 Tecnologias Utilizadas
ChatGpt e Canva

## 🧐 Processo de Criação
Foi utilizado o ChatGpt para pesquisa e criação de um texto com liguagem natural para ser aplicado da imagem e o Canva para criação da imagem, contando com orientações dadas pelo ChatGPT.

## 🚀 Resultados
O material permite um conhecimento básico sobre a modalidade de investimento, mas precisa ser complementado com material que explique melhor outras características.

## 💭 Reflexão (Opcional)
Foi uma excelente experiência, pois possibilitou a produção usando duas ferramentas.
